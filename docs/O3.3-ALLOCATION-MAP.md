## 7. Implemented Architecture — **O3.3**

```
┌─────────────────────────────────────────────────────────────────┐
│                      IMemoryProvider (Platform)                 │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐              │
│  │  Alloc      │  │  Free       │  │  Region     │              │
│  │  (size,     │  │  (ptr,      │  │  (base,     │              │
│  │   align)    │  │   size)     │  │   size)     │              │
│  └─────────────┘  └─────────────┘  └─────────────┘              │
└─────────────────────────────────────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│                      EngineHeap (Core)                          │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  Platform Memory Region (pinned byte[] / IntPtr + size) │   │
│  │  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐   │   │
│  │  │ Alloc    │ │ Free     │ │ Mark     │ │ Root     │   │   │
│  │  │ Linked   │ │ List     │ │ Stack    │ │ Table    │   │   │
│  │  │ List     │ │ (headers)│ │ (IntPtr[])│ │ (IntPtr[])│   │   │
│  │  └──────────┘ └──────────┘ └──────────┘ └──────────┘   │   │
│  └─────────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  Heap Object Layout (in platform memory)                │   │
│  │  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐            │   │
│  │  │ Header │ │ String │ │ Array  │ │ Object │ ...       │   │
│  │  │ (kind, │ │ (utf8, │ │ (len,  │ │ (class,│            │   │
│  │  │  mark, │ │  offs) │ │  items)│ │  fields)           │   │
│  │  │  size) │ └────────┘ └────────┘ └────────┘            │   │
│  │  └────────┘                                            │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

**Key Implementation Details:**
- `HeapObjHeader` (40 bytes): `Kind(1) + pad(3) + Size(4) + Next(IntPtr) + Prev(IntPtr) + Marked(1) + Handle(IntPtr)`
- Root table: `IntPtr[]` in platform memory, geometric growth (256 → 512 → ...)
- Mark stack: `IntPtr[]` in platform memory, geometric growth (1024 → 2048 → ...)
- `GCHandle` bridges managed `HeapObject` to platform header (Hosted only)
- Mark-sweep: roots → mark stack → scan object graph via `GCHandle.Target` → sweep unmarked headers, free `GCHandle`
